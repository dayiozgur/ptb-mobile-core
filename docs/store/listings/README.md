# Store listing drafts (tr / en)

One file per app. Drafts for the owner to edit — nothing here has been entered in a console.

Rules applied (the website copy rules)

- Only capabilities that the mobile app ships today. Web-only features are not mentioned.
- No supplier, hosting-location, framework or competitor names; no prices.
- Hosting other than the cloud service is "per project".
- Product terms: CRM — Potansiyel, Fırsat, Satış Hattı, Firma, Sorumlu; FixFlow — Talep; PMS — Site.
- Android has no remote push notifications yet: the texts say "notifications" only in the iOS
  sense where they mention a platform, and otherwise describe the in-app notification list.
- The AI assistant line must be removed if the assistant is switched off in the store builds
  (see the readiness document, privacy section).

Field limits used

| Field | Limit |
|---|---|
| App Store name | 30 characters |
| App Store subtitle | 30 characters |
| App Store keywords | 100 characters, comma separated, no spaces needed |
| App Store promotional text | 170 characters |
| Google Play title | 30 characters |
| Google Play short description | 80 characters |
| Google Play full description / App Store description | 4000 characters |

Every app needs, per language: a privacy policy URL, a support URL and screenshots — not part of
these drafts.

"What's new" for the first release is the same idea in every app: first release.
